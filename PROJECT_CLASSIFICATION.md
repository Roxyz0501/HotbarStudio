# Hotbar Studio

New standalone plugin requested in this project's original-plugin scope on 2026-10-24. No upstream plugin clone. Author: Roxyz0501.

User requests normal/cross, shared/job/PvP previews, single-slot and whole-bar copying, multiple destinations, drag copy/move. Initially command-based; user subsequently authorized local hotbar changes beyond commands, provided no custom packets are sent.

References: aers/FFXIVClientStructs (MIT), SDK types and local hotbar/user-file APIs; Square Enix Lodestone text-command documentation. Shared StandardPluginTabs copied unchanged from project template. Configuration persistence pattern adapted from this project's Command Atlas by Roxyz0501 (MIT).
